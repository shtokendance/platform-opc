# Loop 1 Specification：Deploy-OPC 左侧导航

## 页面与适用边界

页面为 `/admin/deploy` 的 Deploy-OPC 管理后台。条款仅覆盖导航、页面框架及其与既有四个业务模块的连接，不覆盖模块内部的列表排序、表单字段或提交规则；这些行为保持现状。

### BND-001 管理台鉴权保持不变（R10）

未认证访问继续由既有 `adminauth.ConsolePage` 处理。已认证管理员可看到导航和既有业务内容。不得新增匿名导航 API、绕过鉴权的页面副本或新的权限角色。

### BND-002 左侧导航完整可见（R1、R6）

桌面显示固定左侧导航，依次提供“应用管理”“基础资源”“Dockerfile 模板”“存储与卷”。同步控制台与系统导航位于侧栏其他入口。右侧不再出现原顶部横向 Tab。当前项显示浅绿色背景、绿色文字和左侧 3px 指示条，并带 `aria-current="page"`；非当前项只有悬停浅色反馈。

### BND-003 统一模块切换（R4、R8）

点击菜单或概览卡必须调用同一模块切换逻辑，不刷新页面。合法输入仅为 `apps`、`resources`、`templates`、`storage`。切换后 `activeTab`、当前菜单、顶栏标题、当前业务区和 `#<tab>` 必须一致。代码内部收到其他值时保持当前状态，不发送业务请求。

### BND-004 初始 hash 与恢复（R4、R7）

无 hash 时默认 `apps`；合法 hash 初次打开对应模块。每次合法切换用 `history.replaceState` 同步 hash。监听 `hashchange`，后续手工改成合法 hash 时切换工作区，不整页刷新。

### BND-005 非法 hash 回退（R4、R7）

初次加载或 `hashchange` 得到空值、未知值、大小写变体或带额外字符的值时，回退到 `apps` 并将地址修正为 `#apps`。不得把 hash 拼接到 API 路径、HTML 或动态代码中，不得执行其中的内容。

### BND-006 存储模块加载保持既有语义（R2、R10）

进入 `storage` 菜单或概览卡时调用既有 `loadStorageData()`。顶栏“刷新数据”继续执行既有 `refreshAll()`。存储读取失败继续使用既有 `storageError` 和提示语义；导航不得吞掉异常、伪造成功状态或新增重试循环。

### BND-007 既有入口和业务操作保持可用（R3、R10）

“同步控制台”继续链接 `/admin`，“系统导航”继续链接 `/admin/nav`。“新增基础服务资源”“新增 Dockerfile 模板”“刷新存储大盘”仅在其对应模块显示并调用原有方法。表格、搜索、弹窗、抽屉及写操作的用户流程不得因框架调整改变。

### BND-008 桌面和中屏布局（R2、R9）

视口 ≥1024px 时侧栏宽 224px 并显示文字；768–1023px 时侧栏宽 72px，仅显示图标并提供模块名称提示。内容列分别预留相同宽度且设置可收缩的最小宽度。四张概览卡仅在 ≥1280px 使用四列；较窄视口使用一列或两列。宽表格在自身容器横向滚动，不撑破工作区。

### BND-009 手机抽屉导航（R9）

视口 <768px 时侧栏默认移出屏幕，顶栏显示菜单按钮。打开后显示 224px 抽屉和遮罩；点击遮罩、关闭按钮、任一模块或 Escape 均可关闭。抽屉关闭后焦点回到菜单按钮。不得在手机端恢复顶部横向 Tab，也不得让隐藏抽屉覆盖或拦截工作区操作。

### BND-010 键盘与可读性（R6、R9）

导航、概览卡和菜单按钮均可键盘操作。图标按钮具有可访问名称；当前项和焦点状态可辨识。菜单文字在完整侧栏可读，图标栏通过 `title` 和 `aria-label` 保留名称。响应式只改变呈现，不复制多份会分叉的业务状态。

### BND-011 层级与业务弹窗（R2、R10）

手机导航遮罩和抽屉层级必须低于既有业务弹窗，业务弹窗打开时仍位于最上层。隐藏导航不得遮挡 toast、表格操作或弹窗。既有 `z-50` 业务弹窗样式不变。

### BND-012 无新增数据与接口（R10）

本轮不新增或修改 HTTP API、数据库字段、浏览器持久化存储和凭据处理。除既有模块 API 外，导航切换不得发出额外写请求。停止条件：若实现需要改变上述任一约束，必须停止并回到架构/需求确认。

## 状态机

导航由有限 `activeTab` 和布尔 `mobileNavOpen` 组成，没有业务单据状态变化。

| 当前状态 | 触发与守卫 | 下一状态 | 允许操作与异常 |
| --- | --- | --- | --- |
| 未初始化 | 页面挂载，合法 hash | 对应 tab，手机导航关闭 | 加载既有数据 |
| 未初始化 | 无/非法 hash | `apps`，手机导航关闭，hash 修正 | 不执行 hash 内容 |
| 任一 tab | 选择相同合法 tab | 当前 tab，hash 不变 | 手机导航关闭；存储重复刷新允许，无额外写操作 |
| 任一 tab | 选择另一合法 tab | 目标 tab，hash 同步 | 进入存储时读取存储数据 |
| 任一 tab | 内部非法 tab | 原 tab 与 hash | 忽略，不请求业务 API |
| 任一 tab | hashchange 为合法目标 | 目标 tab | 不整页刷新 |
| 任一 tab | hashchange 为非法值 | `apps`，hash 修正 | 不整页刷新 |
| 手机导航关闭 | <768px 且点击菜单按钮 | 手机导航打开 | 显示抽屉和遮罩 |
| 手机导航打开 | 选择/遮罩/关闭/Escape | 手机导航关闭 | 当前 tab 仅在选择合法模块时改变 |
| 任一显示状态 | 视口变为 ≥768px | 桌面/图标导航，手机抽屉状态复位 | 不改变 activeTab |

## 权限矩阵

| 对象与状态 | 未认证访客 | 已认证管理员 | 可见与只读约束 |
| --- | --- | --- | --- |
| 页面，未初始化 | 既有登录跳转/拒绝行为 | 可初始化 | 不新增可见业务字段 |
| 四个 tab 中任一状态 | 不可见业务内容 | 可切换和执行既有操作 | 权限与模块原实现一致 |
| 手机导航打开/关闭 | 不可见业务内容 | 可打开、关闭、选择 | 仅导航状态变化，不授予新权限 |
| 非法 hash/非法内部 tab | 不可见业务内容 | 回退或忽略 | 不泄露数据、不执行输入 |

## 错误语义与安全

- 导航没有新的服务端错误类型；既有登录、API、存储和表单错误处理保持不变。
- hash 只参与四值枚举比较，不做 HTML 注入、网络参数或动态执行。
- 不引入第三方脚本、新依赖、浏览器存储或遥测。
- 部署失败时停止后续环境推进，保留旧镜像和配置；不得为完成部署清理数据库或其他共享服务。

## 验收场景

### ACC-001 桌面导航与操作（BND-002/003/007）

在 ≥1280px 视口依次点击四个菜单和四张概览卡，验证标题、高亮、hash、业务区同步；检查同步控制台、系统导航、刷新、新增和存储刷新入口。

### ACC-002 四值 hash 恢复（BND-004/006）

分别直接打开 `#apps`、`#resources`、`#templates`、`#storage`，刷新后仍显示对应模块；进入存储时既有读取成功或显示既有错误。

### ACC-003 非法输入边界（BND-003/005/012）

打开空 hash、`#unknown`、`#Apps`、`#apps/extra`，均回退 `#apps`；监听期间修改 hash 行为一致。页面无脚本错误，hash 不产生额外网络写请求。

### ACC-004 手机导航（BND-009/010/011）

在 375px 视口打开抽屉，验证四个模块、遮罩、关闭按钮、Escape 和焦点返回；页面内容无横向溢出，既有弹窗仍在最上层。

### ACC-005 图标栏和中间宽度（BND-008）

在 768px、1023px、1024px 检查 72/224px 切换、工作区预留宽度、卡片列数和表格滚动，验证图标名称和当前项仍可辨识。

### ACC-006 失败与权限回归（BND-001/006/011）

未认证访问仍按原逻辑跳转或拒绝；模拟既有存储读取失败时显示原错误语义，导航仍可切换。关闭失败请求后无重复重试或新增写操作。

### ACC-007 业务与部署回归（BND-007/012）

执行非破坏性业务冒烟：搜索、查看列表、打开并取消既有弹窗；标准测试和构建通过。测试及正式环境均运行同一 `release` 提交镜像，健康检查和以上关键导航场景通过，旧镜像可回滚。
